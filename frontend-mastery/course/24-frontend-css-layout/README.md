# 6. CSS layout: size, flow, Flexbox, and Grid

**Beginner · about 2 hours with practice**

Choose a layout from content behavior and debug overflow instead of adding random widths.

## Use it

Support dashboards with sidebars, toolbars, and long technical content.

**Benefit:** Responsive pages that survive real content.

**Cost or limit:** Nested min-size and overflow rules require inspection.
