# One valid repair

Identify the cache layer that supplied the stale read. Invalidate/revalidate its path or tag, or choose an explicit uncached read where appropriate for the pinned Next version.

Refreshing the client payload alone does not necessarily invalidate server data. Test freshness and permission scope together.

**How to check:** The directive defines a module boundary for client behavior. It is not a blanket browser-only execution promise.

Other repairs are acceptable if they satisfy the stated rule. Explain the failure timeline and show a relevant test.

Code length and matching keywords are not evidence.
