# 22. Vue tests: behavior, timing, and contracts

**Intermediate · about 2 hours with practice**

Write component tests for failed saves, async races, and accessible interaction.

## Use it

Changes to complex forms and route-driven panes.

**Benefit:** Repeatable evidence for failure paths.

**Cost or limit:** Mocks and simulated DOM tests have limits.
