## Trace the execution

Follow a search from URL to accepted rows. Follow an edit from input to versioned request to reconciled response.

Follow a failed save back to a preserved draft. Finally trace an old request that arrives after navigation and prove it has no ownership.

Add one production-style change: a new optional status from the server. Decide how older clients render it.

A strict parser can reject unexpected data; a tolerant adapter can preserve unknown states. Choose deliberately.
