# 16. Composables: reusable behavior without hidden global state

**Intermediate · about 2 hours with practice**

Extract reactive behavior with explicit inputs, lifecycle cleanup, and a predictable return API.

## Use it

Selection, pagination, subscriptions, and reusable editor behavior.

**Benefit:** Reuse behavior without giant components.

**Cost or limit:** Hidden singleton state and implicit dependencies can make bugs travel.
