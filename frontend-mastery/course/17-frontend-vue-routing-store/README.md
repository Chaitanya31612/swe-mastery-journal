# 18. Vue Router and Pinia: choose where state lives

**Intermediate · about 2 hours with practice**

Use URL state, component state, and stores deliberately, including route changes and server rendering.

## Use it

Multi-workspace support dashboards.

**Benefit:** Shareable context and predictable navigation.

**Cost or limit:** Stores can become dumping grounds without ownership rules.
