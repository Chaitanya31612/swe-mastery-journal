# Follow the execution

Trace user intent → action → immediate feedback → result → recovery. During saving, prevent accidental duplicate actions while explaining progress. On failure, keep the input and offer retry. If a modal closes, restore focus to the control that opened it.

Use a performance profile to find the long task behind an unresponsive click. Split work, reduce unnecessary rendering, or virtualize a genuinely large list after measuring. Do not add memoization to every line without evidence.
