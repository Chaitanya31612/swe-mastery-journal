# 2. JavaScript values at API boundaries

**Beginner · about 2 hours with practice**

Distinguish missing, null, false, zero, and shared nested state when adapting API data.

## Use it

Support forms with optional flags, numeric limits, and editable tag lists.

**Benefit:** Fewer invisible defaulting and Cancel bugs.

**Cost or limit:** Boundary validation and draft ownership require explicit decisions.
