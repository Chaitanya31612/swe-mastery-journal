# 11. Promises: overlap, cancel, and limit work

**Intermediate · about 2 hours with practice**

Choose sequential or parallel work and prevent stale results without losing useful failures.

## Use it

Dashboards, typeahead, and attachment uploads.

**Benefit:** Less avoidable waiting and fewer stale screens.

**Cost or limit:** Parallel requests need per-operation ownership and limits.
