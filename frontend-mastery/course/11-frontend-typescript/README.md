# 5. TypeScript: make invalid states harder to express

**Beginner · about 2 hours with practice**

Model request states and narrow outside data instead of hiding uncertainty with any.

## Use it

API adapters and reusable Vue components.

**Benefit:** Missing states and unsafe property reads surface earlier.

**Cost or limit:** Types still need runtime validation at outside boundaries.
