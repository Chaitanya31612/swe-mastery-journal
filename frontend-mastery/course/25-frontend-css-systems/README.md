# 13. CSS cascade, tokens, and component states

**Intermediate · about 2 hours with practice**

Explain why a style wins and build consistent states without escalating selector strength.

## Use it

**Benefit:** Predictable styles and consistent interactions.

**Cost or limit:** System-wide changes need representative state checks.
