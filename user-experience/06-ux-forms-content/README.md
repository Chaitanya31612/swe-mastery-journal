# 7. Forms, words, and decision-friendly defaults

**Intermediate · about 2 hours with practice**

Write labels, hints, validation, and empty states that help users act correctly.

## Use it

Operational forms and bulk actions with meaningful consequences.

**Benefit:** Reduces confusion without adding long tutorials.

**Cost or limit:** Concise language still needs domain accuracy and localization.
