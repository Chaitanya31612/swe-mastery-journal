# 1. Start with the user’s task, not the screen

**Beginner · about 2 hours with practice**

Turn a vague feature request into a task, context, success condition, and recovery path.

## Use it

Feature scoping and UX review for operational workflows.

**Benefit:** Connects interface decisions to outcomes people need.

**Cost or limit:** A task hypothesis still needs observation; a tidy diagram is not user evidence.
