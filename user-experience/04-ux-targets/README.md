# 4. Targets, pointing, touch, and motor effort

**Beginner · about 2 hours with practice**

Design controls that are easy to reach and distinguish, beyond making icons larger.

## Use it

Dense toolbars, table actions, and mobile operational screens.

**Benefit:** Reduces avoidable motor errors and missed controls.

**Cost or limit:** Space is limited; target design must balance density and task needs.
