# 3. Choice, memory, and progressive disclosure

**Beginner · about 2 hours with practice**

Reduce decision effort while keeping useful options discoverable.

## Use it

Export dialogs, status menus, and complex settings.

**Benefit:** Makes choices easier without arbitrarily deleting capability.

**Cost or limit:** Disclosure and defaults can hide important options if poorly chosen.
