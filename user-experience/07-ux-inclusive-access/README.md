# 5. Accessibility as a foundation for usable interaction

**Beginner · about 2 hours with practice**

Check semantics, names, focus, contrast, motion, and zoom as part of the main flow.

## Use it

Every reusable component and critical business flow.

**Benefit:** Improves access and often clarifies interaction for everyone.

**Cost or limit:** Custom widgets carry ongoing keyboard and semantics responsibilities.
