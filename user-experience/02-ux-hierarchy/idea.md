## Understand the idea

People scan before they read closely. Visual grouping suggests relationships.

Nearby controls look related. Similar styling suggests similar purpose.

A border around a group can imply a shared context. These are useful perceptual tendencies, not rules that override every task.

Give the page a primary question. A ticket page might answer “What needs attention now?” Use headings and spacing to distinguish queue context, the main record, and secondary details.

If every element is bright and bold, none has priority.

Visual order and keyboard/reading order should agree. CSS can move a button visually while leaving its document position confusing.

Use semantic headings and a sensible source order. Do not make color the only signal for priority or failure.
