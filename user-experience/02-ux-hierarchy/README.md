# 2. Perception, grouping, and information hierarchy

**Beginner · about 2 hours with practice**

Use proximity, similarity, alignment, and contrast to make the page’s structure understandable.

## Use it

Dense dashboards and responsive ticket pages.

**Benefit:** Reduces search effort without removing needed information.

**Cost or limit:** Grouping can mislead if it implies a relationship the behavior does not honor.
