# 6. Feedback, errors, undo, and honest progress

**Intermediate · about 2 hours with practice**

Design visible system state and recovery for slow, failed, and partially completed work.

## Use it

Exports, bulk changes, uploads, and background jobs.

**Benefit:** Builds accurate expectations and supports recovery.

**Cost or limit:** Honest progress needs observable backend states, not only frontend animation.
