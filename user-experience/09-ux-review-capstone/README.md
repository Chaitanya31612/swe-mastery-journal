# 9. A repeatable UX review and redesign workshop

**Intermediate · about 2 hours with practice**

Review a workflow using task evidence, interaction principles, accessibility, and measurable outcomes.

## Use it

Daily frontend reviews and a portfolio-quality workflow redesign.

**Benefit:** Turns UX knowledge into a repeatable engineering/design habit.

**Cost or limit:** A review still needs user and implementation evidence.
