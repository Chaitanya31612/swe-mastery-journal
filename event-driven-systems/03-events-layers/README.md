# 3. Kafka layers: clients, brokers, storage, replicas, controllers

**Beginner · about 2 hours with practice**

Follow one record through discovery, batching, append storage, replication, and consumer fetch.

## Use it

Debugging Kafka by layer instead of treating it as one box.

**Benefit:** A concrete model for network, storage, and coordination symptoms.

**Cost or limit:** A local flow demo cannot certify production durability or performance.
