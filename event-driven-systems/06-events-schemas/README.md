# 6. Event envelopes, evolution, and privacy

**Beginner · about 2 hours with practice**

Define event identity, entity key, business version, time, and a compatible payload contract.

## Use it

Long-lived event contracts across teams/releases.

**Benefit:** Less coupling and clearer replay/debugging.

**Cost or limit:** Compatibility, retention, and private-data scope require governance.
