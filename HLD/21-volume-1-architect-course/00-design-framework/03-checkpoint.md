# Framework checkpoint — select and explain

Choose one answer per question and explain why a tempting alternative fails. Do not open the answer folder first.

1. An interviewer says “design a calendar.” What is the best first move?
   - A. Choose a distributed database.
   - B. Clarify core actions, sharing/conflicts, and scope.
   - C. Calculate all global storage immediately.
   - D. Draw every component used by a commercial calendar.
2. A design contains a queue. Which observation best demonstrates understanding?
   - A. The queue is popular at large companies.
   - B. A queue always eliminates failure.
   - C. You can trace durable acceptance, retries, and recovery after a worker crash.
   - D. The queue icon appears in the book.
3. Which estimate is most useful for a streaming-video deep dive?
   - A. Egress bytes/second derived from concurrent viewers and bitrate.
   - B. Number of REST routes.
   - C. Employee count.
   - D. Exact username length regardless of workload.
4. Two viable designs meet the contract. How should you choose?
   - A. Always select more microservices.
   - B. Choose the diagram matching the book.
   - C. Choose the database with the most familiar name.
   - D. Compare failure behavior, cost, complexity, and expected evolution.
