# Follow the execution

Classify the failure: missing file, invalid JSON, or valid but wrong settings shape. They are different contracts. The block closes the file. The rescue above handles only invalid JSON; it leaves missing-file behavior visible to the caller.

Write one test for a valid input, one malformed input, and one legitimate false value. A unit test can prove the parser contract. It cannot prove Rails boot, Sidekiq delivery, or production permissions.
