# 16. Time zones, schedules, and jobs that run twice

**Intermediate · about 2 hours with practice**

Separate an instant, a local calendar rule, a schedule trigger, and a unique business run.

## Use it

Daily reports, reminders, and tenant-local deadlines.

**Benefit:** Prevents common duplicate and off-by-a-day defects.

**Cost or limit:** Calendar changes and ambiguous outcomes need explicit policy.
