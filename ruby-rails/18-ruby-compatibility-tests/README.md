# 18. Compatibility and boundary tests for a legacy Rails stack

**Intermediate · about 2 hours with practice**

Plan a small change or upgrade using version-specific tests rather than broad rewrites.

## Use it

Small legacy changes and planned runtime upgrades.

**Benefit:** Confidence comes from relevant evidence rather than a total rewrite.

**Cost or limit:** A compatibility matrix still has gaps outside tested seams.
