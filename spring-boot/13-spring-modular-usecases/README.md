# 13. Use-case boundaries and practical modular design

**Intermediate · about 2 hours with practice**

Separate transport, business rules, persistence, and external adapters without creating needless layers.

## Use it

Features called from controllers, imports, and jobs.

**Benefit:** Rules remain reusable and easier to test.

**Cost or limit:** Unnecessary abstractions can obscure a simple feature.
