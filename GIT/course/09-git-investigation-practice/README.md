# 9. Reflog, bisect, and exact-snapshot investigation

**Intermediate · about 2 hours with practice**

Combine recovery and regression search without destroying unrelated working edits.

## Use it

Regression investigations and accidental branch movements.

**Benefit:** Evidence without sacrificing unrelated work.

**Cost or limit:** Historical environments and expired objects limit recovery/search.
