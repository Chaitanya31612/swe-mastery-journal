# One valid repair

Confirm who depends on the published commits, preserve the old tip, communicate the rewrite, and choose a safe agreed recovery plan.

Prefer avoiding the rewrite if shared history need not change. --force-with-lease checks an expected remote tip but does not replace coordination.

**How to check:** A commit ID covers its content and metadata, including its parent relationship.

Other repairs are acceptable if they satisfy the stated rule. Explain the failure timeline and show a relevant test.

Code length and matching keywords are not evidence.
