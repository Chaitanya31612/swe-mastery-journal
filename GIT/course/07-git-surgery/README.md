# 7. Cherry-pick, revert, and moving a fix deliberately

**Intermediate · about 2 hours with practice**

Move a small fix between release lines and distinguish patch replay from history preservation.

## Use it

Backports and shared-history repairs.

**Benefit:** Small fixes can move without unrelated features.

**Cost or limit:** Dependencies and merge semantics can make a small patch nontrivial.
