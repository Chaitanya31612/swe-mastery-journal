## Understand

Short-term context is what the current request sees. Durable application state can include conversations, task progress, user preferences, evidence snapshots, tool outcomes and pending approvals.

These stores are not the model's weights.

Retain only what serves a purpose. A summary can lose an exception, change an uncertain statement into a fact, or preserve a malicious instruction.

Keep source IDs and confidence/status labels with summaries. Treat stored memories as outside data on future turns.

A memory key must include the relevant identity and scope. Recheck current access before reusing records or facts.

A user's old permission does not authorize today's retrieval. Define retention, correction and deletion across derived caches and summaries.

Product memory should not grow forever merely because storage is cheap.
