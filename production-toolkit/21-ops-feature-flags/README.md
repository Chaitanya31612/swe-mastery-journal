# 21. Feature flags: release control without permanent branching

**Intermediate · about 2 hours with practice**

Use a flag to limit exposure and define defaults, ownership, removal, and data compatibility.

## Use it

Controlled rollout of a risky workflow change.

**Benefit:** Smaller exposure and deliberate rollback decisions.

**Cost or limit:** State combinations, provider failure, and stale flags add complexity.
