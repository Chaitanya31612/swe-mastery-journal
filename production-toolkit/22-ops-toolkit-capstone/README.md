# 22. Choose the tools, then debug the whole application

**Intermediate · about 2 hours with practice**

Explain a production tool map and recover a synthetic incident without adding every tool by default.

## Use it

An end-of-course tool selection and incident exercise.

**Benefit:** Connects tools to responsibilities and practical diagnosis.

**Cost or limit:** A reference architecture is not a requirement to deploy every part.
