# 5. Datadog: turn traces and monitors into an investigation

**Beginner · about 2 hours with practice**

Connect Rails requests, jobs, SQL, and provider calls with useful service identity and bounded telemetry.

## Use it

Investigating Rails/worker latency and release regressions.

**Benefit:** Integrated signals and investigation workflows.

**Cost or limit:** Compatibility, sampling, volume, cost, and sensitive-data policy need ownership.
