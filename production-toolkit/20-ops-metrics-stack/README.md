# 10. Prometheus and Grafana: collect a signal, then ask a question

**Beginner · about 2 hours with practice**

Explain metric collection, labels, rates, dashboards, and alert ownership without treating a graph as evidence by itself.

## Use it

Open observability stacks and interpreting operational dashboards.

**Benefit:** Flexible metric queries and shared operational views.

**Cost or limit:** Collection, cardinality, retention, and alerting need operation.
