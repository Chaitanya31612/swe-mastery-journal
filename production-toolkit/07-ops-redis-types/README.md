# 4. Redis foundations: pick a data structure for the question

**Beginner · about 2 hours with practice**

Choose strings, hashes, sets, sorted sets, lists, and streams from access patterns.

## Use it

Counters, memberships, ranked projections, and caches.

**Benefit:** Useful atomic data operations and low-latency access.

**Cost or limit:** Memory, round trips, key lifecycle, and cross-store consistency remain.
