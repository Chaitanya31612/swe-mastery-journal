# 19. GitHub Actions: test, build once, and promote an artifact

**Intermediate · about 2 hours with practice**

Design a CI/CD path with explicit permissions, artifact identity, and release gates.

## Use it

Rails/Vue delivery with reproducible artifacts.

**Benefit:** Repeatable checks and reviewable promotion.

**Cost or limit:** Runner trust, secrets, caches, and release compatibility need design.
