# 18. Terraform: desired infrastructure with state and review

**Intermediate · about 2 hours with practice**

Explain configuration, plan, state, drift, and the effect of apply without treating a plan as a harmless toy.

## Use it

Repeatable cloud infrastructure changes.

**Benefit:** Reviewable configuration and resource change plans.

**Cost or limit:** State, drift, provider behavior, and destructive changes require care.
