# 19. Secrets Manager and KMS: credentials and encryption keys are different

**Intermediate · about 2 hours with practice**

Deliver secrets and authorize key use without confusing encryption with application access.

## Use it

Database credentials and private object encryption.

**Benefit:** Central secret/key lifecycle and access control.

**Cost or limit:** Rotation, caching, and multiple policy layers need operational tests.
