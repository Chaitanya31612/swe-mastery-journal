# 15. EventBridge: route integration events by meaning

**Intermediate · about 2 hours with practice**

Configure an explicit event bus/rule/target contract and debug a missing delivery.

## Use it

AWS integrations and structured application-event routing.

**Benefit:** Managed routing/filtering and service integration.

**Cost or limit:** Offering-specific contracts, per-entry failures, and target policies need attention.
