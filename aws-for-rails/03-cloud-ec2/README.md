# 3. EC2 and EBS: when you own the machine

**Beginner · about 2 hours with practice**

Explain instance lifecycle, disk persistence, process supervision, and the responsibilities EC2 leaves with you.

## Use it

Understanding existing VM deployments and choosing compute ownership.

**Benefit:** Flexible machine-level control.

**Cost or limit:** Patching, configuration drift, and recovery remain your work.
