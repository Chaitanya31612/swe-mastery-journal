# 17. EKS: Kubernetes control plane does not operate your application

**Intermediate · about 2 hours with practice**

Choose EKS for a concrete Kubernetes need and map AWS responsibility versus cluster/workload responsibility.

## Use it

Teams with a justified Kubernetes platform need.

**Benefit:** Managed Kubernetes integration and ecosystem access.

**Cost or limit:** Workload/platform lifecycle remains substantial.
