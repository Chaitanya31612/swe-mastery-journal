# 16. ECS with Fargate: web and workers as separate services

**Intermediate · about 2 hours with practice**

Configure task definitions, roles, networking, logs, health, and scaling for Rails web and worker processes.

## Use it

A containerized Rails app without a Kubernetes requirement.

**Benefit:** Managed orchestration with direct AWS integration.

**Cost or limit:** Networking, release flow, identity, and capacity limits remain explicit.
