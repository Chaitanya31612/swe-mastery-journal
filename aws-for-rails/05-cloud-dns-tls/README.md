# 5. Route 53 and ACM: names and trust before the request

**Beginner · about 2 hours with practice**

Explain DNS records, certificate validation, region constraints, and what a DNS change does not instantly control.

## Use it

Custom domains and reliable traffic cutovers.

**Benefit:** Managed names and supported certificate lifecycle.

**Cost or limit:** Caching, validation, service scope, and renewal ownership still matter.
