# 9. CloudWatch: logs, metrics, alarms, and a useful runbook

**Beginner · about 2 hours with practice**

Connect an application symptom to a metric, trace/log identity, alarm, and recovery check.

## Use it

Rails API and worker operations.

**Benefit:** AWS-native signal collection and alerting.

**Cost or limit:** Signal volume, cardinality, retention, and alert noise need design.
